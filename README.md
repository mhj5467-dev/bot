# 🤖 Abu Yazid Bot — SPX Options Trading Assistant

بوت تداول خيارات SPX مع واجهة سطح مكتب عربية كاملة.

---

## 📋 المتطلبات

- Python 3.10 أو أحدث
- اتصال بالإنترنت (لجلب بيانات SPX)
- حساب Telegram Bot (اختياري للإشعارات)

---

## ⚡ التثبيت السريع

```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt

# 2. تشغيل البوت
python main.py
```

---

## 🏗️ هيكل المشروع

```
spx_bot/
├── main.py                 # نقطة البداية
├── requirements.txt        # المكتبات المطلوبة
├── ui/
│   └── app.py             # واجهة المستخدم (Tkinter)
├── core/
│   ├── analyzer.py        # تحليل SPX (Pin Score, Levels)
│   ├── database.py        # قاعدة البيانات (SQLite)
│   ├── telegram_bot.py    # إشعارات التيليغرام
│   └── exporter.py        # تصدير Excel
└── data/
    └── trades.db          # قاعدة بيانات الصفقات (تنشأ تلقائياً)
```

---

## 🔧 الإعداد

### إعداد Telegram Bot:
1. افتح @BotFather في التيليغرام
2. أرسل `/newbot` وأعطِه اسماً
3. انسخ الـ Token
4. افتح البوت في التيليغرام واحصل على Chat ID من @userinfobot
5. ادخل Token و Chat ID في تبويب "الإعدادات" في البوت

---

## 📊 الميزات

| الميزة | الوصف |
|--------|--------|
| تحليل SPX | يجلب سعر SPX + سلسلة الخيارات تلقائياً |
| Pin Score | يحسب احتمالية التثبيت عند مستوى مغناطيسي |
| مستويات الدعم/المقاومة | Call Wall, Put Wall, Expected Move |
| تيليغرام | يرسل التحليل والصفقات تلقائياً |
| تتبع الصفقات | يحفظ الصفقات ويحسب الإحصائيات |
| تصدير Excel | تقارير مُنسَّقة باللغة العربية |
